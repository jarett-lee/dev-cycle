# Coding sessions are longer and use more context

- **Source:** https://claude.com/resources/articles/claude-opus-5-5-built-for-coding-sessions-that-use-more-context
- **Author:** Michael Segner (Anthropic)
- **Published:** 2026-09-24
- **Supports:** context and chunking (see `TODO.md`)

A model launch post. The figures are Anthropic's aggregate Claude Code usage
from March to September 2026.

## Snippets

> Claude works 3.3x longer on each prompt with more than 40% more model calls per prompt. There are 68% fewer interruptions.

> Context per request has grown 2.6x.

> All of this points to developers aiming a harder working, better informed Claude toward bigger, more open-ended tasks.

## Takeaways

- In 2026, sessions run longer, carry more context, and get interrupted by
  people less often. That's a moving target for how big a chunk of a project
  Claude can hold at once.
- This is vendor data from a launch post; treat it as a trend, not a
  measurement to design around.
