# CLAUDE.md

This repo is documentation only: it defines a software development cycle for
Claude. See `README.md` for the layout.

## Snippets

- One file per source in `snippets/`, named `<publisher>-<slug>.md`, with the
  same header fields as the existing files (source URL, author, date).
- Text in a blockquote must be verbatim from the source. Fetch the page and
  copy from it; never quote from memory or paraphrase inside a blockquote. Mark
  cuts with `…`. If you can't fetch a source, list it under "To collect" in
  `snippets/README.md` instead.
- Keep quotes short, a few sentences each, and link to the source for the rest.
- Your own commentary goes under "Takeaways", never inside a quote.
- Add each new snippet file to the index in `snippets/README.md`.

## Principles

`principles.md` holds the owner's design principles in the owner's order. Don't
reorder them or add new ones without being asked.
